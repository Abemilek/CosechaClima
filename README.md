## Desarrollo Local

### 1. Instalar dependencias
Asegúrate de tener Node.js instalado (v18 o superior).
```bash
npm install
```

### 2. Iniciar el servidor de desarrollo
```bash
npm run dev
```

### 3. Crear el build de producción
Para generar los archivos estáticos optimizados (minificados):
```bash
npm run build
```
Esto creará una carpeta `/dist` con los archivos HTML/CSS listos. Puedes previsualizar este resultado localmente con:
```bash
npm run preview
```
